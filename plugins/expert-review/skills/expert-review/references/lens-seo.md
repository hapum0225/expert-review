# 렌즈: SEO · AEO · GEO에 유리한 코드 구성 (약자 E) v0.1

> 시험 상태: **미시험** — 실제 프로젝트에 1회 써 봤을 뿐, 정답이 있는 시험물로 재 보지 않았다.

점검 항목의 출처 문서는 다시 확인하지 않았다(모델 지식 기준). 등급: 확립 = 공식 문서·표준이 있는 것 / 방향성 = 관행·연구 / 추정 = 근거가 약한 것.
참고: Google은 공식 안내에서 AI 개요 · AI 모드를 위한 별도 최적화가 필요 없다고 밝혔다. 그래서 E13 · E14는 낮은 등급이며, 없다고 감점하지 않는다.

| 항목 | 예/아니오로 물을 것 | 등급 |
|---|---|---|
| E1 색인 가능성 | robots 설정이 공개 페이지를 막지 않는가. noindex가 필요한 곳(관리자 · 개인 페이지)에 있는가 | 확립 |
| E2 사이트맵 | 사이트맵을 만드는 코드가 있고 공개 페이지를 담는가 | 확립 |
| E3 렌더링 방식 | 공개 콘텐츠가 서버에서 HTML로 나오는가(클라이언트에서만 그려지지 않는가) | 확립 |
| E4 메타데이터 | 페이지별 제목 · 설명이 있고 겹치지 않는가. 동적 페이지에 맞춤 메타데이터가 있는가 | 확립 |
| E5 표준 주소 | canonical 지정, 쿼리 · 정렬 변형으로 생기는 중복 주소 | 확립 |
| E6 구조화 데이터 | JSON-LD가 해당 유형(조직 · 행사 등)에 있고 필수 속성을 갖는가 | 확립(지원 유형에 한해) |
| E7 공유 미리보기 | Open Graph · 카드 메타, 대표 이미지 | 방향성 |
| E8 문서 구조 | 페이지당 h1 하나, 제목 위계, 의미 있는 태그, 이미지 대체 글, `lang="ko"` | 확립 |
| E9 내부 링크 | 공개 페이지끼리 `a href`로 닿는가(버튼 클릭 이동만 있는 곳). 없는 페이지 · 이동 처리 | 확립 |
| E10 성능 코드 패턴 | 이미지 최적화와 크기 지정, 글꼴 로딩, 큰 클라이언트 묶음 — 실제 수치는 미실측 | 확립 |
| E11 주소 설계 | 읽을 수 있는 주소인가, 불필요한 내부 ID가 드러나지 않는가 | 방향성 |
| E12 네이버 | 서치어드바이저 소유 확인 메타 · 사이트맵 제출 흔적, robots가 네이버 검색 로봇을 막지 않는가 | 방향성(공식 원문 미열람) |
| E13 답변형 · 생성형 검색 | 질문과 답 형태의 콘텐츠 블록, 요약 문단, FAQ 구조화 데이터 | 방향성 · 추정 |
| E14 llms.txt | 유무만 적는다 | 추정(효과 근거 없음) |

이 렌즈가 판단하지 못하는 것: 실제 순위 · 유입 · 색인 상태 · 속도 측정값(코드만 본다).
