# 렌즈: 개발 설계 (약자 D) v0.1

> 시험 상태: 비교 시험 1회(파일 검토 · 2026-10-01) — README 「검증 상태」 참조.

점검 항목의 출처 문서는 다시 확인하지 않았다(모델 지식 기준). 등급: 확립 = 공식 문서·표준이 있는 것 / 방향성 = 관행·연구 / 추정 = 근거가 약한 것.

| 항목 | 예/아니오로 물을 것 | 등급 |
|---|---|---|
| D1 구조 | 화면 · 서버 로직 · 데이터 접근의 경계가 일관된가(같은 일을 여러 곳에서 다르게 하지 않는가) | 방향성 |
| D2 쓰기 경로의 검증 | 데이터를 바꾸는 경로마다 입력 · 권한 검증이 서버 쪽에 있는가 | 확립 |
| D3 원자성 | 여러 테이블을 바꾸는 작업이 한 묶음으로 성공하거나 실패하는가(중간에 실패하면 어떤 상태가 남는가) | 확립 |
| D4 중복 실행 | 재시도 · 중복 클릭 · 동시 요청에 안전한가(신청 · 결제 · 출결 · 배정 등) | 확립 |
| D5 오류 처리 | 실패가 삼켜지지 않고 사용자와 기록에 드러나는가 | 방향성 |
| D6 DB 변경 관리 | 마이그레이션 · SQL이 순서 · 재실행 안전성 · 되돌리기를 갖는가. 운영 실행 절차(리허설 · 복원 구획)가 있는가 | 방향성 |
| D7 삭제 · 탈퇴 · 보존 | 개인정보 삭제 · 익명화 경로가 관련 테이블을 빠짐없이 다루는가. 외래 키 · 고아 데이터 | 확립 |
| D8 테스트 전략 | 핵심 과업과 큰 실패 경로에 자동 테스트가 있는가. 테스트가 검사 대상 코드로 기대값을 만들지 않는가 | 방향성 |
| D9 운영 | 배포 · 되돌리기 절차, 개발/운영 환경 분리, 예약 작업의 중복 실행 방지와 실패 알림 | 방향성 |
| D10 비밀값 · 설정 | 비밀값이 코드 · 저장소에 없는가(값은 보지 않고 위치만). 환경 변수가 없을 때의 동작 | 확립 |
| D11 성능 · 규모 | 반복 조회(N+1), 끝없는 목록, 인덱스 없는 조회 조건 | 방향성 |
| D12 관측 | 주요 실패를 나중에 추적할 기록이 있는가. 기록에 개인정보를 남기지 않는가 | 방향성 |
| D13 기술 부채 | 죽은 코드 · 중복 구현 · 임시 우회가 핵심 경로에 남았는가 | 방향성 |
| D14 문서와 코드의 일치 | 계획서 · spec · 규칙 문서가 말하는 것과 코드가 다른 곳 | 확립(프로젝트 규칙) |

이 렌즈가 판단하지 못하는 것: 실제 부하 · 운영 사고 여부 · 운영 DB의 현재 상태(파일 기준으로만 본다).
